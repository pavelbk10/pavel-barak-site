# PAVEL BARAK — אתר תדמית למעצב אתרים

אתר תדמית מקצועי ופוטוריסטי עבור **פבל ברק (PAVEL BARAK)** — מעצב ובונה אתרים.
האתר בעברית מלאה (RTL), מותאם לנייד, עם המון אנימציות, תוכן SEO, ונגישות.

## מבנה האתר

- `index.html` — דף הבית (הירו, שירותים ומחירים, תיק עבודות, אודות, מאמרים, שאלות נפוצות, יצירת קשר)
- `css/style.css` — כל העיצוב
- `js/main.js` — כל האינטראקטיביות (אנימציות, חלקיקים, ולידציה, ווידג'ט נגישות)
- מאמרים: `article-*.html`
- פרויקטים / תיק עבודות: `project-*.html`
- `accessibility.html`, `privacy.html` — הצהרת נגישות ומדיניות פרטיות
- `robots.txt`, `sitemap.xml` — קבצי SEO

## טכנולוגיות

- HTML5 סמנטי + ARIA לנגישות
- CSS3 (Custom Properties, Glassmorphism, גרדיאנטים ואנימציות)
- Vanilla JavaScript (IntersectionObserver, Canvas particles)
- גופנים: Heebo + Orbitron (Google Fonts)
- SEO: Open Graph, Twitter Cards, Schema.org JSON-LD
